#Incident Response & Cyber Threat Intelligence
A practical incident response and cyber threat intelligence project based on a simulated logistics organisation, Winderby Logistics Group (WLG). The project focused on identifying attack paths, improving incident response capabilities, assessing security maturity, and modelling threat intelligence.

##Technologies & Frameworks

STIX 2.1 • ENISA SIMv2 • Incident Response • Attack Trees • Threat Intelligence • Network Segmentation • IT/OT Security • Security Policies

## Work Completed

* Developed an attack tree identifying realistic attack paths involving phishing, credential abuse, vulnerable infrastructure, lateral movement and IT/OT compromise.
* Assessed weaknesses across incident response, access control, network security, logging, backup/recovery, security awareness, asset management and third-party security.
* Developed a structured Incident Response Policy covering incident reporting, classification, escalation, containment, recovery, documentation and post-incident review.
* Redesigned the organisation’s security architecture with firewall controls, DMZ placement, IT/OT segmentation and isolation of legacy infrastructure.
* Performed an ENISA SIMv2 maturity assessment across Organisation, Human, Tools and Processes, identifying gaps and target improvements.
* Built a STIX 2.1 threat intelligence model linking threat actors, infrastructure, vulnerabilities, attack patterns and malware.
* Analysed attack relationships involving public-facing services, credential abuse, PowerShell, WMI/lateral movement and warehouse OT systems.

## Key Outcome

Produced an end-to-end security improvement model connecting threat analysis, incident response, security governance, maturity assessment, network architecture and threat intelligence.
